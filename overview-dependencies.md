# Dependencies

## 📦 Dependencies Utama

### Core Framework

- **Next.js 16** - React framework dengan App Router (Latest Stable)
- **React 19** - UI library (Latest Stable)
- **TypeScript 5.7+** - Type safety
### UI & Styling

- **Tailwind CSS 4** - Utility-first CSS
- **shadcn/ui** - Component library (New York style)
- **Radix UI** - Headless UI primitives
- **Framer Motion** - Animation library
- **Iconsax React** - Icon library
- **Lucide React** - Additional icons

### State Management

- **Zustand** - Lightweight state management
- **Rematch** - Redux-based state management
- **React Query (TanStack Query)** - Server state management

### Forms & Validation

- **React Hook Form** - Form management
- **Yup** - Schema validation
- **@hookform/resolvers** - Form validation resolvers

### API & HTTP

- **Axios** - HTTP client
- **Socket.io Client** - WebSocket client

### Real-time Communication

- **Socket.io Client** - WebSocket untuk real-time communication
- **LiveKit** - Video/audio streaming dan real-time communication

### Animation & Motion

- **GSAP** - Advanced animation library
- **Framer Motion** - React animation library
- **Tailwind CSS Animate** - CSS animations

### Rich Text & Content

- **TipTap** - Rich text editor framework
- **React Markdown** - Markdown rendering
- **KaTeX** - Math formula rendering

### Data Visualization

- **Chart.js** - Chart library
- **React Chart.js 2** - React wrapper untuk Chart.js

### Media & File Handling

- **React PDF** - PDF viewer
- **React Dropzone** - File upload dengan drag & drop
- **React Webcam** - Webcam access
- **RecordRTC** - Audio/video recording
- **Hark** - Speech detection

### Utilities

- **Lodash** - Utility functions
- **Date-fns / Dayjs** - Date manipulation
- **UUID** - Unique ID generation
- **PapaParse** - CSV parsing
- **Classnames / clsx** - Conditional className
- **Tailwind Merge** - Merge Tailwind classes

### Internationalization

- **next-i18next** - i18n for Next.js
- **next-intl** - Additional i18n support
